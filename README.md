# MaidLink

Локальный ИИ-компаньон для Windows: персонажи с памятью и характером, которые
меняются от общения. Языковая модель (Gemma 4 через llama.cpp) работает на вашей
видеокарте, переписка никуда не отправляется.

Лицензия — [PolyForm Noncommercial 1.0.0](LICENSE). Сторонние компоненты —
[THIRD-PARTY-LICENSES.txt](THIRD-PARTY-LICENSES.txt), что скачивается при первом
запуске — [NOTICE.md](NOTICE.md). Программа только для взрослых (18+); при
установке и первом запуске принимается [пользовательское соглашение](TERMS.txt).

## Системные требования

| | |
|---|---|
| Система | Windows 10 или 11, 64-бит |
| Видеокарта | NVIDIA от 8 ГБ видеопамяти с актуальным драйвером (CUDA 13); для Gemma 4 31B — 16–24 ГБ |
| Диск | около 9 ГБ: приложение и базовая модель Gemma 4 12B; с моделью 31B — до 17 ГБ; модуль рисования — ещё несколько гигабайт |
| Интернет | для первой загрузки моделей |

Видеокарты AMD и Intel не поддерживаются: модель работает на видеокарте через CUDA.

## Установка

1. Скачайте `MaidLink-Setup-<версия>.exe` из [релизов](../../releases). Устанавливайте
   на диск, где хватит места: модели ложатся в папку установки.
2. У установщика нет цифровой подписи, поэтому SmartScreen покажет «Система Windows
   защитила ваш компьютер» — нажмите «Подробнее», затем «Выполнить в любом случае».
3. Мастер первого запуска предложит модель с рекомендуемым объёмом видеопамяти
   и скачает её вместе с библиотеками NVIDIA CUDA и модулем рисования.
4. Персонажи — файлы `.maid` из [релизов](../../releases). Перетащите файл в окно
   выбора персонажа.

### Проверка установщика

К каждому релизу прикладываются контрольные суммы SHA-256 (`SHA256SUMS.txt`).
Сверить сумму скачанного файла:

```powershell
Get-FileHash .\MaidLink-Setup-<версия>.exe -Algorithm SHA256
```

## Модели

| Модель | Рекомендуемая видеопамять | |
|---|---|---|
| Gemma 4 12B QAT Q4_0 | 8 ГБ | базовая: быстрая, понимает картинки |
| Gemma 4 31B IQ3_XXS | 16 ГБ | умнее 12B и заметно быстрее самой тяжёлой; картинки не понимает |
| Gemma 4 31B Q3_K_XL | 24 ГБ | самая умная и медленная; картинки не понимает |

Объём видеопамяти — рекомендация, а не запрет: если памяти меньше, часть модели
уйдёт в оперативную память, и ответы станут медленнее. Модель выбирается в мастере
первого запуска, сменить её можно в настройках.

## Где хранятся данные

Всё — в папке установки, на вашем диске:

```
MaidLink\
└─ userdata\
   ├─ models\       модели
   ├─ characters\   персонажи и их память
   └─ runtime\      библиотеки NVIDIA
```

Персонажа можно зашифровать паролем: без него память и переписку не прочитать.
При удалении приложение спрашивает, удалять ли `userdata`; по умолчанию папка остаётся.

## Когда приложение выходит в сеть

Телеметрии нет: приложение никому не сообщает ни о себе, ни о вас. Сеть нужна только здесь:

| Когда | Куда |
|---|---|
| Первый запуск: модель и библиотеки NVIDIA | `huggingface.co`, `github.com` |
| Установка модуля рисования | `github.com` (ComfyUI и расширения), `huggingface.co` (модели) |
| «Найди…» — поиск в интернете | `duckduckgo.com` |
| Картинки и арт по вашей просьбе | `danbooru.donmai.us` и сайты из выдачи поиска |
| Погода — по вашей просьбе | `open-meteo.com` |
| Видео — когда вы просите включить ролик | плеер YouTube |
| Ссылки | открываются в вашем браузере |

## Рисование

Отдельный модуль на ComfyUI, ещё несколько гигабайт. Мастер первого запуска ставит
его сам вместе с моделью. Компоненты под лицензией AGPL-3.0 (Impact Subpack и
детекторы лица и рук) — только по отдельной галке: без них рисование не
заработает, доставить их можно позже в настройках → «Рисование». Чекпойнт
(`.safetensors`) приложение не скачивает: свой файл перетащите туда же. Без
модуля рисования чат и всё остальное работают.

## Сборка установщика

Нужны Windows 10/11 x64, [Node.js](https://nodejs.org) 20+ и Python 3.12+
(с лаунчером `py`). Из корня репозитория:

```bash
npm ci
npm ci --prefix ui
py build/fetch_llama_server.py
npm run dist
```

`fetch_llama_server.py` скачивает пришпиленную сборку llama.cpp в `llama-server/`,
`npm run dist` собирает интерфейс, бэкенд (PyInstaller, отдельное окружение
`build/venv_build`) и установщик NSIS. Тексты лицензий компонентов собираются в
`build/dist/licenses` и ставятся в папку `licenses` рядом с программой.
Результат — `release/MaidLink-Setup-<версия>.exe`.

## Чего нет в репозитории

- Модели и библиотеки NVIDIA CUDA — их скачивает мастер первого запуска.
- Персонажи — файлы `.maid` / `.butler`, импортируются перетаскиванием в окно выбора.
- Модуль рисования (ComfyUI) — его ставит мастер первого запуска, чекпойнт — свой файл.

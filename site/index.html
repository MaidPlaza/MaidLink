    Приватность

    Только между вами

    Комплименты, неловкие признания, разговоры до ночи — переписка хранится на твоём компьютере. Нам её читать незачем, да и доступа к ней у нас нет.

    Её дом — твой компьютер

    Переписка, воспоминания и файл героини хранятся у тебя. Для общения не нужны аккаунт, подписка или облачный сервис.

    Без отчётов о тебе

    MaidLink не собирает статистику использования. Интернет нужен для первого запуска и сетевых запросов: поиска, погоды, картинок и видео. Просто поболтать можно без сети.

    Для любопытных есть пароль

    Поставь пароль на персонажа. Без него никто не прочитает вашу переписку и то, что героиня о тебе помнит.

    Любишь проверять? Загляни в код

    Исходный код MaidLink открыт. Можно посмотреть, как всё устроено, и свериться с README на GitHub.

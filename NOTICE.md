# MaidLink — что скачивается и откуда

MaidLink распространяется **тонким установщиком**: модели и тяжёлые библиотеки в него
не входят — при первом запуске они скачиваются из официальных источников. Вы
получаете их напрямую от авторов и под их лицензиями.

## При первом запуске
- **Библиотеки NVIDIA CUDA** (CUDA Runtime, cuBLAS) — чтобы модель работала на
  видеокарте. Источник: релиз llama.cpp на GitHub (та же сборка, что llama-server в
  установщике). Лицензия NVIDIA CUDA EULA (распространяемые компоненты). При
  обновлении с версии 0.6.7 или раньше библиотеки докачаются сами.
- **nomic-embed-text v1.5** — модель для поиска по памяти. Источник: Hugging Face,
  `nomic-ai/nomic-embed-text-v1.5-GGUF`. Лицензия Apache-2.0.
- **Языковая модель — одна, по вашему выбору в мастере** (сменить её можно позже в
  настройках — тогда скачается выбранная). Все — Apache-2.0, источник Hugging Face:
  - **Gemma 4 12B** (QAT Q4_0, GGUF) с проектором для картинок —
    `google/gemma-4-12B-it-qat-q4_0-gguf`; к ней модель для ускорения ответов (MTP) —
    `unsloth/gemma-4-12b-it-GGUF`.
  - **Gemma 4 31B IQ3_XXS** (GGUF) — `unsloth/gemma-4-31B-it-GGUF`.
  - **Gemma 4 31B Q3_K_XL** (GGUF) и модель для ускорения ответов (MTP) к ней —
    `unsloth/gemma-4-31B-it-GGUF`.

Модели складываются в `userdata\models`, библиотеки CUDA — в `userdata\runtime`
внутри папки установки.

## Модуль рисования (ставит мастер первого запуска)
Мастер ставит его вместе с моделью; компоненты под AGPL-3.0 — только с вашего
отдельного согласия (без них рисование не заработает; доставить их можно позже в
настройках → «Рисование»). Без модуля снимки выключены — всё остальное работает.
При установке модуль скачивает:
- **ComfyUI** — движок генерации (GitHub, Comfy-Org). Лицензия GNU GPL-3.0.
- **ComfyUI Impact Pack** — GPL-3.0; **Impact Subpack** — GNU AGPL-3.0 (ставится
  только с вашего отдельного согласия).
- **Детекторы лица и рук YOLO** (`Bingsu/adetailer`, Ultralytics) — AGPL-3.0 (только
  с вашего отдельного согласия).
- **SAM ViT-H** (Meta) — Apache-2.0.
- **isnet-anime** — отделение персонажа от фона (сборка rembg). Apache-2.0.

**Чекпойнт рисования** (.safetensors) не скачивается: файл вы добавляете сами и
принимаете его лицензию (например, семейство NoobAI идёт под Fair AI Public License —
некоммерческая).

В установщик вшиты эмбеддинги рисования lazypos, lazyneg, lazyhand и lazywet (Lazy
Embeddings, civitai.com/models/1302719) — лицензия Fair AI Public License 1.0-SD.

## Сеть
MaidLink работает локально: модель — на вашей видеокарте, переписка никуда не
отправляется, телеметрии нет. В интернет приложение выходит только здесь:

| Когда | Куда |
|---|---|
| Первый запуск: модели и библиотеки CUDA | `huggingface.co`, `github.com` |
| Установка модуля рисования | `github.com`, `huggingface.co` |
| «Найди…» — поиск в интернете | `duckduckgo.com` |
| Картинки и арт по вашей просьбе | `danbooru.donmai.us` и сайты из выдачи поиска |
| Погода — по вашей просьбе | `open-meteo.com` |
| Видео — когда вы просите включить ролик | плеер YouTube |
| Ссылки | открываются в вашем браузере |

Исходный код открыт — всё это можно проверить.

в папке установки (список — `licenses\INDEX.txt`); сводка — THIRD-PARTY-LICENSES.txt.
